Multiple Linear Regression

Simple Linear Regression predicted second semester grade from a single predictor. This page adds more predictors. Adding predictors never makes the fit to the training data worse, so the question is whether the model predicts better.

Overview of Multiple Linear Regression

Multiple linear regression extends the simple linear regression framework to include more than one predictor:

  • more than one feature (also called the predictors or independent variables),
  • one target (also called the outcome or dependent variable).

It models the relationship between a single outcome \(Y_i\) and multiple predictors \(X_{1i}, X_{2i}, \dots, X_{pi}\) for each observation \(i = 1, \dots, n\).

The Model

\[ Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \dots + \beta_p X_{pi} + \varepsilon_i \]

where:

  • \(Y_i\): the outcome for observation \(i\).
  • \(X_{ji}\): the value of predictor \(j\) for observation \(i\).
  • \(\beta_0\): the intercept, the expected value of \(Y_i\) when all \(X_{ji} = 0\).
  • \(\beta_j\): the coefficient for predictor \(X_{ji}\), the expected change in \(Y_i\) for a one unit increase in \(X_{ji}\), holding all other predictors constant.
  • \(\varepsilon_i\): the error term, capturing variation not explained by the predictors.

Estimating the Model

The coefficients are estimated by ordinary least squares, which chooses the values minimizing the residual sum of squares:

\[ \text{RSS} = \sum_{i=1}^n (y_i - \hat{y}_i)^2 \]

This is the same loss function idea from the previous page. Nothing about the learning procedure changes when you add predictors. There are simply more coefficients to search over.

Implementation in R

Predictors are joined with + on the right hand side of the formula.

fit_mlr <- lm(grade_sem2 ~ grade_sem1 + admission_grade, data = completers)

coef(fit_mlr)
    (Intercept)      grade_sem1 admission_grade 
    3.220254141     0.674053933     0.007326894

Interpreting Coefficients

Each \(\beta_j\) reflects the unique contribution of its predictor, after adjusting for the others.

b <- coef(fit_mlr)
  • The intercept, 3.22, is the predicted second semester grade for a student with a first semester grade of 0 and an admission grade of 0. Neither is possible, so treat it as the number the equation needs rather than a claim about any student.
  • The coefficient on grade_sem1, 0.674, is the predicted change in second semester grade for a one point increase in first semester grade, holding admission grade constant.
  • The coefficient on admission_grade, 0.007, is the predicted change for a one point increase in admission grade, holding first semester grade constant.

Admission grade on its own is related to second semester grade, but much of what it tells you is already contained in the first semester grade. Its coefficient reports only what it adds.

WarningHolding Constant Is Not an Intervention

“Holding admission grade constant” describes a comparison between students who already differ. It does not describe what would happen if you changed somebody’s admission grade.

A coefficient is a statement about an association in this dataset. Turning it into a claim about what an intervention would do requires assumptions this model cannot supply.

Interactions

An interaction occurs when the effect of one predictor depends on the level of another. In other words, one variable is moderated by another.

\[ Y_i = \beta_0 + \beta_1 X_{1i} + \beta_2 X_{2i} + \beta_3 (X_{1i} \cdot X_{2i}) + \varepsilon_i \]

where \(\beta_3\) captures the interaction, and \((X_{1i} \cdot X_{2i})\) is the product of the two predictors. If \(\beta_3 \neq 0\), the effect of \(X_1\) on \(Y\) changes depending on \(X_2\).

Without an interaction, the model assumes each predictor contributes independently, which may oversimplify reality.

# The colon creates the product term
fit_interaction <- lm(
  grade_sem2 ~ grade_sem1 + admission_grade + grade_sem1:admission_grade,
  data = completers
)

coef(fit_interaction)
               (Intercept)                 grade_sem1 
               6.701053190                0.405048615 
           admission_grade grade_sem1:admission_grade 
              -0.019620445                0.002074745

ImportantWhat the Table Shows

Going from one predictor to ten improved cross validated RMSE by roughly 0.014 grade points. On a 20 point scale that is a very small change.

Training fit never gets worse when you add a predictor. Predictive accuracy can, and here it barely changed even though several of those predictors are individually significant.

The noise predictor example showed the same gap with random variables. Here it appears with real ones. This is the motivation for the regularization methods in the next chapter, which penalize predictors that do not improve prediction.

Model Concerns

Linear regression is widely used largely because its coefficients are easy to interpret. But it relies on several strong assumptions, and those assumptions are violated more often as predictors accumulate. Violations can produce biased estimates, misleading interpretations, and poor predictions.

Linearity

The model assumes the change in the outcome for a one unit change in a predictor is constant across the whole range of that predictor. Many real relationships are not like that.

Number of units passed in the first semester is a good example.

p1 <- ggplot(train, aes(units_sem1, grade_sem2)) +
  geom_point(size = 1, alpha = .2) +
  geom_smooth(se = FALSE, color = "orange") +
  labs(x = "Units passed, first semester", y = "Second semester grade",
       title = "A curved relationship") +
  theme_minimal(base_size = 13)

p2 <- ggplot(train, aes(units_sem1, grade_sem2)) +
  geom_point(size = 1, alpha = .2) +
  geom_smooth(method = "lm", formula = y ~ x + I(x^2), se = FALSE, color = "steelblue") +
  labs(x = "Units passed, first semester", y = "Second semester grade",
       title = "A squared term follows it") +
  theme_minimal(base_size = 13)

gridExtra::grid.arrange(p1, p2, nrow = 1)

A straight line through the left panel would underfit badly. Adding a squared term roughly doubles the variance this predictor accounts for:

c(
  linear    = summary(lm(grade_sem2 ~ units_sem1, data = train))$r.squared,
  quadratic = summary(lm(grade_sem2 ~ units_sem1 + I(units_sem1^2), data = train))$r.squared
)
    linear  quadratic 
0.05954114 0.12027644

Transformations of the predictors, or of the outcome, are often enough to make a relationship approximately linear. The model is still a linear model, because it remains linear in its coefficients.

Heteroskedasticity

Heteroskedasticity means the variance of the errors is not constant across levels of the predictors, violating the homoscedasticity assumption.

df1 <- broom::augment(cv_model1$finalModel, data = train)

ggplot(df1, aes(.fitted, .std.resid)) +
  geom_point(size = 1, alpha = .3) +
  geom_hline(yintercept = 0, linetype = "dashed") +
  labs(x = "Predicted values", y = "Standardized residuals",
       title = "Model 1", subtitle = "grade_sem2 ~ grade_sem1") +
  theme_minimal(base_size = 13)

Look for a funnel shape, where the spread of residuals widens or narrows systematically as predictions get larger. Remedies include transforming the outcome or using robust standard errors.

Heteroskedasticity mainly affects inference, because the standard errors and p values covered in Inference in Linear Regression assume constant variance. The predictions can still be accurate.

Autocorrelation

Autocorrelation occurs when residuals are correlated with each other, violating the independence assumption. It underestimates standard errors and produces overly optimistic p values. It matters most with a time component or with repeated measures on the same people. Each row here is a different student measured once, so we do not pursue it, though it becomes important with intensive longitudinal data.

Feature Importance

The vip() function (Variable Importance Plots) visualizes the relative importance of predictors. It accepts any fitted model object, including lm(), glm(), random forests, and boosted trees.

For linear models, vip() ranks predictors by the absolute value of their t statistics.

vip(cv_model4, num_features = 10, method = "model")
