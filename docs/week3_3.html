Simple Logistic Regression

Simple Linear Regression predicted a continuous outcome.

This page keeps the same machinery, except the outcome is now dichotomous (0/1).

Setup

library(dplyr)   # data manipulation and the pipe
library(ggplot2) # plots

Overview of Simple Logistic Regression

Simple logistic regression is used when the target (outcome) variable is binary (e.g., success/failure, yes/no, 0/1) and we have a single feature (predictor).

Instead of modeling the outcome directly, logistic regression models the probability of the event occurring.

  • \(Y \in \{0,1\}\) is the binary target (outcome variable)

  • \(X\) is the feature (predictor variable)

  • \(p(x) = P(Y=1 \mid X=x)\) is the probability of success given \(X\)

This Is a Classification Problem

Problem Classes in ML separates supervised problems by the type of the target. A continuous target makes it a regression problem. A categorical target makes it a classification problem. Dropping out is a category, so everything on this page is classification, despite the word regression in the name.

The name is not an accident. The model is a linear model, and it is fit the same way, but what it returns is a probability:

  • The model predicts \(P(Y = 1 \mid X = x)\), a number between 0 and 1.
  • That probability becomes a predicted class only once you apply a cutoff, which is 0.5 by default.
  • The cutoff is a separate decision from the model. Multiple Logistic Regression shows what changes when you move it.

Two consequences follow, and both come up later:

  • The evaluation measures change. MAE and RMSE measure distance in the units of a continuous outcome, and there is no distance between two categories. Classification uses accuracy, sensitivity, specificity, and related measures, all built from the confusion matrix. See Evaluating Model Performance.
  • The baseline changes. For a continuous outcome the do nothing baseline predicts the mean. For a category it predicts the most common class. About 32 percent of these students dropped out, so predicting that nobody drops out is already right 68 percent of the time.

Starting From Linear Regression

Suppose we want to model a binary outcome \(Y \in \{0,1\}\) (e.g., pass/fail, success/failure). At first, we might think of using linear regression:

\[ \hat{Y} = \beta_0 + \beta_1 X \]

and interpret \(\hat{Y}\) as the probability that \(Y=1\).

Problems with Using Linear Regression for Binary Outcomes

Predicted probabilities outside [0,1]:

Linear regression does not constrain predictions. For some values of \(X\), \(\hat{Y}\) might be negative or greater than 1, which is impossible for probabilities.

Let’s fit a regression to binary data to make this concrete.

set.seed(123)

# Simulate some data
n <- 100
x <- runif(n, -3, 3)              # predictor
p <- 1 / (1 + exp(-(-0.5 + 1*x))) # true logistic relationship
y <- rbinom(n, 1, p)              # binary outcome

sim <- data.frame(x, y)

# Fit linear regression (treat y as numeric 0/1)
lm_fit <- lm(y ~ x, data = sim)

# Predictions across a grid of x values
x_grid <- data.frame(x = seq(-3, 3, length.out = 200))
x_grid$lm_pred <- predict(lm_fit, newdata = x_grid)

ggplot(sim, aes(x, y)) +
  geom_point(alpha = 0.6) +
  # The dashed lines mark 0 and 1, the only values a probability can take
  geom_hline(yintercept = c(0, 1), linetype = "dashed", color = "gray40") +
  geom_line(data = x_grid, aes(x, lm_pred), color = "orange", linewidth = 1) +
  labs(x = "x", y = "Predicted and observed") +
  ylim(-0.2, 1.2) +
  theme_minimal(base_size = 14)

The line dips below 0 on the left, so it already returns predictions that cannot be probabilities. Extend x a little past 3 and it climbs above 1 as well.

Non-constant variance (heteroskedasticity):

In binary data, the variance of \(Y\) is

\[ \mathrm{Var}(Y) = p(1-p) \]

which depends on \(p\). The spread of residuals will be smallest near \(p=0\) or \(p=1\) and largest near \(p=0.5\). That is heteroskedasticity. Linear regression assumes constant variance (homoskedasticity), so its assumptions are violated.

Let’s show this visually.

sim$fitted    <- fitted(lm_fit)
sim$residuals <- residuals(lm_fit)

ggplot(sim, aes(fitted, residuals)) +
  geom_point(alpha = 0.6) +
  geom_hline(yintercept = 0, color = "orange", linewidth = 1) +
  labs(x = "Fitted values", y = "Residuals") +
  theme_minimal(base_size = 14)

The residuals fall on two parallel lines, one for the cases with \(y = 1\) and one for those with \(y = 0\). Near fitted values of 0 and 1 almost every point sits on one of the two lines, so the spread is narrow. Near 0.5 both lines are occupied and the spread is at its widest. That is the changing variance the formula describes.

Nonlinear relationship between predictors and probability:

In reality, probabilities often follow an S shaped curve. They change slowly when predictors are very small or very large, and change more quickly in the middle. Linear regression cannot capture this shape.

Can you think of a real-world example where this might happen?

Logistic Regression Solution

Logistic regression fixes these problems by modeling the log-odds of success as a linear function:

\[ \text{logit}(p(x)) = \ln \left(\frac{p(x)}{1-p(x)}\right) = \beta_0 + \beta_1 X \]

This ensures:

  • Predicted probabilities are always between 0 and 1: \[ p(x) = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x)}} \]
  • The variance is modeled correctly.
  • The S shaped curve naturally captures how probabilities change with \(X\).

How Does the Algorithm Learn?

Simple Linear Regression described fitting as a search: choose the coefficients that make a loss function as small as possible. That description still holds here. What changes is the loss.

Squared error is the wrong loss for a probability, because the outcome is 0 or 1 while the prediction is a number in between. The standard choice is log loss, also called cross entropy:

\[ \text{log loss} = -\frac{1}{n}\sum_{i=1}^{n} \left[ y_i \ln(\hat{p}_i) + (1 - y_i) \ln(1 - \hat{p}_i) \right] \]

  • When \(y_i = 1\), only the first term counts, and the loss grows as \(\hat{p}_i\) moves toward 0.
  • When \(y_i = 0\), only the second term counts, and the loss grows as \(\hat{p}_i\) moves toward 1.
  • A confident prediction that turns out to be wrong is punished heavily.

Minimizing log loss is the same thing as maximizing the likelihood, which is why logistic regression is usually described as a maximum likelihood method. Unlike linear regression there is no closed form solution, so glm() solves it by iterating until the coefficients stop changing. The idea from the previous pages does not change: fitting a model means finding the coefficients that minimize a loss function.

Example Data: Dropout Data

Overview

The Predict Students’ Dropout and Academic Success dataset was contributed to the UCI Machine Learning Repository in December 2021.

The dataset is designed for classification tasks:
- Target: Predict whether a student will eventually graduate, remain enrolled without graduating, or drop out.
- Motivation: Enable early identification of students at risk of failure or dropout, supporting targeted interventions.
- Challenge: The outcome classes are imbalanced, which makes predictive modeling more complex.

Dataset link: UCI Repository

Dataset Characteristics

The key characteristics of the dataset are:

Aspect Description

Number of features 36 features (demographic, socio-economic, and educational background)

Target variable Student outcome: dropout, enrolled (non-graduate), or graduate
Missing values No NA values, but see the note below
Timing of features Demographic, socio-economic, and application variables are recorded at enrollment. The academic variables report results from the first and second semesters.
Train/test split The authors used 80% training, 20% testing in their evaluations

ImportantNo NA Values Is Not the Same as No Missing Data

The dataset contains no NA values, which is why the documentation reports it as clean. On Simple Linear Regression we found that a second semester grade of 0 is not a grade at all. It marks a student who completed no curricular units, so the value is a code standing in for a missing grade.

The same caution applies to the academic variables used here.

Feature Categories

Features describing student status at admission include:

  • Demographic information:
    • Age, gender, marital status, nationality
  • Socio-economic background:
    • Parents’ education levels, parents’ occupations, whether the student receives financial support
  • Educational background:
    • Previous qualification type and grade
    • Application mode (how the student applied)
    • Application order (rank of the program in the application list)
  • Enrollment details:
    • Degree program enrolled in
    • Attendance mode (day/evening)

The dataset also records how many curricular units each student enrolled in, approved, and their average grade, for the first and second semesters.

Target Variable

The target variable records the student’s final status.

  • Dropout: the student left without completing the program (1,421 students).
  • Enrolled: the student is still enrolled but has not graduated (794 students).
  • Graduate: the student completed the program (2,209 students).

Logistic regression needs a binary outcome, so we recode this into a single indicator: 1 for students who dropped out, 0 for everybody else. That groups the students who are still enrolled together with the graduates. It is a modeling decision rather than a fact about the data, and a different question, such as who is on track to graduate, would call for a different grouping.

Simple Logistic Regression in R

First, let’s fit an intercept-only model to the data.

Intercept-Only Model in R

In our example the variable Dropout indicates whether a subject dropped out. Let’s start with the simplest model for predicting Dropout, the intercept-only model:

\[ \text{logit}(\pi_i) = b_0 \]

where \(\pi_i = P(\text{Dropout}_i = 1)\).

We can use the glm() function to fit the model to the data

fit_intercept <- glm(
  Dropout ~ 1,
  family = "binomial",
  data = dropout
)

summary(fit_intercept)

Without wanting to get too detailed, we do not need to specify the logit link here because it is the canonical link function for the binomial distribution. This essentially means there is a direct correspondence between the predicted mean and the distribution’s canonical location parameter.

Interpretation of the Intercept-Only Model

In the intercept-only model, the intercept, \(b_0\), reflects

  1. The expected log-odds (\(-0.7482\)) of an individual dropping out.

  2. The odds of dropping out \(\mathrm{exp}(b_0)=0.47\).

exp(-0.7482)
[1] 0.4732176
  1. The expected probability (\(0.32\)) of the a subject dropping out.

\[ P(Dropout_i = 1) = \pi_i = \frac{e^{b_0}}{1+e^{b_0}} \] or, equivalently, in R

exp(-0.7482)/(1 + exp(-0.7482))
[1] 0.3212136

We can also confirm that the backward transformed parameter from this intercept-only logistic regression matches the expectation we get from the descriptives of the raw data.

mean(dropout$Dropout)
[1] 0.3212025

Note: If \(\beta_j > 0\) then \(\mathrm{exp}(b_j) > 1\), indicating a positive relationship between \(X_{j}\) and the probability of the event occurring. If \(\beta_j < 0\), the opposite relationship holds.

Single-Predictor Model in R

OK, let’s include a predictor in our logistic regression model. Let’s start with Age.at.enrollment such that

\[ logit(\pi_i) = b_0 + b_1Age^{*}_{1i} \]

where \(\pi_i = P(Dropout_i = 1)\). Here, \(Age^{*}\) is age at enrollment, mean centered, so a value of 0 corresponds to a student of average age, about 23 years old.

Let’s fit the model in R.

dropout$Age_star <- as.numeric(
  scale(dropout$Age.at.enrollment, center = TRUE, scale = FALSE)
)

fit_pred <- glm(
  Dropout ~ 1 + Age_star,
  family = "binomial",
  data = dropout,
)
summary(fit_pred)

Interpreting the Single-Predictor Model

Again, There are essentially three ways to interpret coefficients from a logistic regression model:

  1. The log-odds (or logit)
  2. The Odds
  3. Probabilities

Log-Odds

The parameter estimate \(b_0\) reflects the expected log-odds (\(-0.776123\)) of dropping out for an individual who is approximately 23 years old (the average age at admission).

The estimate for \(b_1\) indicates the expected difference of the log-odds of dropping out for a 1-year difference in age. Therefore, we expect a \(0.07\) difference in the log-odds of dropping out for a \(1\) year difference in age.

Odds

Parameter estimates from a logistic regression are often reported in terms of odds rather than log-odds. To obtain parameters in odds units, we simply exponentiate the coefficients. Note that this is just one of the steps of the inverse link function (which would take us all the way to probability units).

exp(cbind(OR = coef(fit_pred), confint(fit_pred)))
                   OR     2.5 %    97.5 %
(Intercept) 0.4601866 0.4309351 0.4911538
Age_star    1.0712794 1.0622291 1.0805629

In other words, the odds of dropping out for an average-aged student \(exp(-0.776123) = 0.46\).

In regard to the slope coefficient, for 1-year difference in age, we expect to see about \(7\%\) increase in the odds of dropping out. This increase does not depend on the age of the individual. Note this is significant and we would likely report this interpretation. Essentially, if the odds ratio is equal to one, the predictor did not have an impact on the outcome.

Probability

Finally, we can also interpret the coefficients in terms of probabilities.

Remember, probabilities range from \([0,1]\), whereas log-odds (the output from the raw logistic regression equation) can range from \((-\infty,\infty)\), and odds and odds ratios can range from \((0,\infty)\). Due to the bounded range of probabilities, probabilities are non-linear, but log-odds can be linear.

For example, as age goes up by constant increments, the probability of dropping out will increase by varying amounts, but the log-odds will increase by a constant amount, and the odds will increase by a constant multiplicative factor.

For this reason it is not so simple to interpret probabilities in logistic regression from the coefficient directly. Often it is much simpler to plot the probabilities across a range of the predictor variables.

ggplot(dropout, aes(x = Age_star, y = Dropout)) +
  geom_point(alpha = 0.05, size = 2) +
  stat_smooth(method = "glm", method.args = list(family = "binomial"),
              se = TRUE, color = "orange") +
  labs(x = "Age at enrollment, mean centered", y = "Dropout (0 or 1)") +
  theme_minimal(base_size = 14)

The density of the observations is visualized by manipulating the transparency (alpha) level of the data points. The predicted curve based on our model has a non-linear shape. If we were to plot the relationship on the logit scale instead, it would be a straight line.
